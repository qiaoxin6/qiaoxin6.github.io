关于我

你好，我是 Jo，一名 Java 后端开发者，正在向高级架构的方向进阶。

技术栈

  • 后端：Java / Spring Boot / MyBatis / WebFlux
  • 中间件：Redis / RocketMQ
  • 数据库：MySQL
  • 方向：源码阅读、框架设计、并发编程

正在做的事

  • 🛠️ 连接池 LinkPool：从零手写一个连接池，经历了动态代理、并发控制、超时等待、动态扩容、泄漏检测、空闲驱逐的完整迭代，用 H2 全流程测试验证
  • ⚡ 秒杀系统：Redis → MQ → DB 三阶段架构，攻克库存一致性、MQ 失败处理与 QPS 性能
  • 🔌 AgentToolGateway：基于 WebFlux + LangChain4j 的智能体工具网关，实现熔断与权限控制
  • 🎯 面试备战：目标大厂高级开发，持续输出源码级理解

为什么写这个博客

把「以为懂了」变成「真的懂了」的最好方式，就是把它讲清楚。这里记录技术学习笔记、项目复盘与面试沉淀，也希望能帮助到同样在路上的你。

如果文章有错，欢迎指正；如果想交流，可以在评论区留言。

代码给我写好了啊 —— 开玩笑的，认真写的。
